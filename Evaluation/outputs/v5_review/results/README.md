# Results of the SU Evaluation

This folder holds the result tables of the evaluation reported in Chapter 6 of the thesis *Hybrid Legal AI for Verifiable Legal Answers*. The tables are generated from the legal reviewer's labels (`../simple_reviews.csv`) and the LLM judge's labels (`../../v5_judge_c04_aligned/ai_review_c04_aligned.csv`). The numbers below are read directly from the CSV files in this folder.

The thesis calls the three conditions without source, with correct source and my own RAG system, and it numbers the criteria C01 to C10. The CSV files use the names from the review tool, such as Question only, Correct source supplied and C1. The main README has a table of the terms.

## Who assessed the answers

- **Legal reviewer (human reference).** Patrick Michel assessed all 70 answers himself on the ten criteria, in five rounds of 14 answers: Llama without source, GPT-6-luna without source, Llama with correct source, GPT-6-luna with correct source, and my own RAG system. That is 700 decisions. In the label files, his labels have `reviewer = human`.
- **LLM judge.** Claude Sonnet 5.5 assessed the same 70 answers on the same criteria, with C04 worded exactly as in the legal reviewer's tool, without seeing the legal reviewer's labels, in three separate runs (2,100 decisions). Agreement below uses run 1, and stability counts the answers that got the same label in all three runs.

## Files in this folder

| File | Content |
|---|---|
| `table1_answers.csv` | One row per answer (70), with the legal reviewer's label on each criterion (✓ Met, ✗ Not met, ? Not assessable) and whether the answer is correct and complete (the column is called Legally adequate) |
| `table2_summary.csv` | Counts of Met, Not met and Not assessable per criterion and block (section 1 above) |
| `all_reviews.csv` | All 70 human assessments with labels and reasons, in one file |
| `questions_14.csv` | The 14 questions with topic, the XHAILe determinations they use and the correct source in the 2026 guidance |
| `xhaile_points_34.csv` | The 34 determinations received from XHAILe, with the question that uses each one |

The LLM-judge tables are in `../../v5_judge_c04_aligned/results/`: `table3_agreement.csv` (agreement per criterion, all 70 answers), `table4_stability.csv` (same label in all three runs, all 70 answers) and `judge_agreement_subsets.csv` (section 2 above).

The workbook `results/SU_evaluation_results_2026-11-15.xlsx` at the top of the repository collects the same tables in one file.
